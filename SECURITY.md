# Security Policy

## Supported Versions

The current `main` branch is the supported version of this governance pack.
Older tagged releases are retained for reference, but security fixes are made
against the current line unless maintainers explicitly state otherwise.

## Reporting a Vulnerability

Please do not open a public issue for an undisclosed vulnerability.

Report suspected vulnerabilities through a private channel maintained by the
repository owner, such as GitHub private vulnerability reporting when enabled or
the maintainer contact listed in the repository profile.

Include:

- affected file or artifact
- reproduction steps
- expected and observed behavior
- impact assessment
- suggested fix, if known

Maintainers should acknowledge the report, assess impact, prepare a focused fix,
and document validation before release.
